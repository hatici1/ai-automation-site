XML / EDIFACT FTP / SFTP ERP Integration n8n

XML/EDI FTP Pipeline Modernisation

A logistics company was manually checking an SFTP server for incoming EDIFACT order files, copy-pasting data into their ERP and emailing suppliers to confirm receipt. The entire process took 2–3 hours daily and was error-prone. We built an n8n workflow that polls the SFTP server every 5 minutes, parses EDIFACT D96A messages, validates against the expected schema, transforms the data and pushes it directly into their ERP via REST API. Error alerts go to Slack within seconds of a parse failure.

  • SFTP polling every 5 minutes with automatic file archiving after successful processing.
  • EDIFACT D96A parsing & schema validation with configurable tolerance rules.
  • ERP push via REST API — zero manual data entry, zero copy-paste errors.
  • Slack alerting with error type, file name and line reference on any parse failure.
  • AI anomaly detection flagging duplicate order numbers and quantity outliers.
Result: 2.5 hours of manual work eliminated daily. Zero missed orders in 6 months post-launch.
